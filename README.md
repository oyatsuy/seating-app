# 學生座位表產生器

給老師使用的網頁版排座位工具：自動排座、手動微調、匯出 Excel／列印 PDF。

**使用網址：https://oyatsuy.github.io/seating-app/**

不用安裝、不用登入，電腦和平板（iPad／Android）的瀏覽器都能開。

## 功能

- 自訂教室列數、排數，可設定黑格子（不能坐的位置）與前／中／後區域
- 學生填志願（前／中／後），老師可強制指定某座號的區域（優先權最高）
- 座位衝突設定：指定兩位同學盡量不要排在九宮格（含對角）內
- 自動排座可無限重骰；「確認並存入歷史」後，下次會避開每位同學上次的座位
- 點擊格子微調：互換、手動指定、移除、黑格子、改區域
- 座位不足時會警告並列出沒排到的同學
- 匯出 Excel、預覽列印／存成 PDF
- 多班級存檔、跨裝置進度代碼、備份檔下載／上傳

## 基本用法

1. 輸入標題、列數、排數，按「產生 / 重置網格」。
2. 輸入學生名單，一人一行：`座號 姓名 志願1 志願2`（志願可不填）。也可以匯入 CSV／文字檔。
3. 視需要設定老師強制設定、座位衝突、幹部名單。
4. 按「自動排座」，不滿意就重骰，再用點擊模式微調。
5. 滿意後按「確認並存入歷史」，最後匯出 Excel 或列印。

網頁左上方也有「使用說明」可以展開查看。

## 資料與隱私

- 所有資料只存在**使用者自己裝置的瀏覽器**（localStorage），不會上傳到任何伺服器，其他老師也看不到。
- 這個 repo 只有程式碼，沒有任何學生資料。
- 換裝置、換瀏覽器、無痕模式、清除瀏覽器資料時，資料不會跟著走或會消失。請定期用「備份檔」下載備份，或用「進度代碼」在兩台裝置間搬資料。
- 備份檔裡有學生姓名，請妥善保管，不要放到公開的地方（例如公開的 GitHub repo）。
